# 🌦️ Weather App

A simple **Weather App** that provides real-time weather information using an external weather API. 

## 🚀 Features
- 🌍 Get current weather details for any city
- 📍 Fetch weather based on user location
- 🌡️ Displays temperature, humidity, wind speed, and weather condition
- 🎨 Simple and responsive UI

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- OpenWeatherMap API (or any other weather API)
- Fetch API / Axios
